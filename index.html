Metodologia e Ferramentas Utilizadas

1. Análise Multicritério (MCDA)

Utilizamos o método de Análise Multicritério para ponderar diferentes fatores:

  • 8 critérios principais identificados
  • Pesos definidos com base em prioridades estratégicas do Magalu
  • Scores calculados com base em dados objetivos e análise qualitativa

2. Análise de Custos (TCO)

Avaliação Total Cost of Ownership considerando:

  • Custos de aquisição de terreno (pesquisa imobiliária regional)
  • Custos de construção (CUB regional + especificações técnicas)
  • Custos operacionais estimados (mão de obra, utilidades, manutenção)

3. Análise Logística

Modelagem de tempos de entrega utilizando:

  • Análise de malha rodoviária (dados DNIT)
  • Velocidades médias por tipo de rodovia
  • Considerações de trânsito urbano nos centros de distribuição

4. Análise de Mercado

Avaliação do potencial de consumo baseada em:

  • Dados demográficos (IBGE 2023)
  • PIB regional e per capita
  • Penetração e crescimento do e-commerce
  • Análise da concorrência regional

5. Análise Financeira

Projeções financeiras utilizando:

  • Fluxo de caixa descontado (VPL)
  • Taxa de desconto: 12% a.a. (WACC Magalu)
  • Horizonte de análise: 5 anos
  • Análise de sensibilidade para diferentes cenários

6. Ferramentas Utilizadas

  • Python para análise de dados e modelagem
  • GIS para análise geoespacial
  • Excel para modelagem financeira
  • APIs de dados econômicos (IBGE, Banco Central)
  • Análise de dados de mercado imobiliário

Conclusão Metodológica

A análise multicritério com base em dados objetivos e metodologia robusta aponta Salvador como a localização estratégica ideal, proporcionando 11,9% de vantagem geral sobre Recife, com destaque para menores custos, melhor ROI e posicionamento logístico superior para atender todo o Nordeste.
